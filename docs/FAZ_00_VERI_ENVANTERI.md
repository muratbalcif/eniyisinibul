# Faz 0 - Veri isleme envanteri

Durum: Teknik taslak; hukuki onay bekleniyor.

| Islem | Veri | Amac |
| --- | --- | --- |
| Urun arama | Arama terimi ve kategori | Urunleri listelemek |
| Amazon yonlendirmesi | Link ve urun kimligi, tiklama kaydi | Yonlendirme ve toplu istatistik |
| Admin girisi | E-posta, parola dogrulamasi, oturum belirteci ozeti | Yetkilendirme |
| Admin oturumu | HttpOnly oturum cerezleri | Oturumu surdurme |

Sunucu erisim loglari, IP adresleri, CDN, analitik, saklama sureleri, ucuncu taraf aktarimlari ve veri sorumlusu rolu uretim altyapisi kesinlesince ayrica dogrulanmalidir.

## Yayina cikis kontrolu
- [ ] Isleme amaclari ve hukuki sebepler kesinlestirildi.
- [ ] Veri saklama ve silme sureleri belirlendi.
- [ ] Ucuncu taraflar ve aktarimlar belirlendi.
- [ ] KVKK aydinlatma metni hukuki kontrolden gecti.
- [ ] Gerekli cerez tercihleri ve ilgili kisi basvuru surecleri test edildi.
